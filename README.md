# AI Code Analyzer

An AI-powered code reviewer: paste code into the editor, click **Review**, and get a structured review generated by Llama 3.3 70B (via Groq).

## Features
- Code editor with syntax highlighting (`react-simple-code-editor` + PrismJS)
- One-click review that sends the code to an Express API
- The backend prompts the LLM as a senior code reviewer covering bugs, code quality, performance, security, best practices, scalability, error handling, structure, naming and documentation
- Review comes back in a fixed format: Overall Assessment, Issues Found, Improvements, Optimized Code, Final Verdict (score out of 10)
- Review is rendered as Markdown in the right-hand panel

## Tech Stack
- **Frontend:** React 19, Vite, Axios, react-markdown, PrismJS
- **Backend:** Node.js, Express 5, Groq SDK (`llama-3.3-70b-versatile`), dotenv, CORS

## API
`POST /ai/get-review` with body `{ "code": "<your code>" }` returns the review as Markdown text (400 if `code` is missing).

## Setup

### Backend
```bash
cd Backend
npm install
echo "GROQ_API_KEY=your_key_here" > .env
node server.js        # runs on http://localhost:3000
```

### Frontend
```bash
cd Frontend
npm install
npm run dev
```
> The frontend currently calls the deployed API (`https://ai-code-analyzer-rvwl.onrender.com/ai/get-review`). To use your local backend, change the URL in `Frontend/src/App.jsx` to `http://localhost:3000/ai/get-review`.

## Project Structure

